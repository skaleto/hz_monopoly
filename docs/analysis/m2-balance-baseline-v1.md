# M1 基线与 M2 首轮候选模拟

- 代码基线：`m1-v0.5.2` 规则经配置化后的等价实现
- 样本：每个 profile 400 局、4 Bot、12 轮
- 固定 seed：从 1 开始
- 统计口径：每条命令返回的完整 events；不使用只保留最近 50 条的 `state.log`
- 原始工件：`artifacts/balance/m2-candidates-v1.json`（验证工作区，不提交）

## 已证明的事实

1. 四个 profile 都能 100% 完成，没有死循环、非法状态或非有限数值；配置化没有破坏 M1 状态机。
2. M1 的分红 P90 只有付款前现金的 6.2%，重组为 0，经济压力确实偏弱。
3. 7×3 分组本身不等于组合目标会自然发生。三组候选的组合完成率最高只有 23.5%，没有达到原设想的 50%–70%。
4. 提高建设倍率可以把单次冲击提高到 14.2%–21.6%，但首轮策略建设约 14 次/局，明显高于目标 4–8 次。
5. 新经济放大了后手初始现金：目标/激进方案第四行动位胜率达到 41.3%/45.8%。M1 的 +100 逐席补偿不能原样搬到 M2。
6. 三组候选的重组率仍只有 0.3%，没有形成预期的偶发失败压力。
7. 分红变重后，最后三轮领先变化反而下降；仅调倍率不会自动产生更好的终局高潮。

## 结论

首轮三个候选都是**有效反例**，不能进入正式 M2：

- cautious：压力接近目标下限，但组合完成反而下降；
- target：分红冲击达标，但行动位公平性和建设频率失败；
- aggressive：冲击最强、组合完成最高，但第四行动位优势和建设过密最严重。

下一轮模拟需要先解决两个结构问题，再继续调倍率：

1. 产业组合需要可主动追逐的获得路径，不能只靠随机落点；候选包括更有方向性的岔路提示、组合补全型机遇，或把组合完成目标从 3/3 分为 2/3 激活、3/3 旗舰两段。
2. 后手补偿必须在新经济下重新标定，并与随机先手一起模拟，不能沿用 M1 的 +0/+100/+200/+300。

模拟只用于排除数值明显失衡的方案。即使下一轮全部指标达标，仍需 6–10 局真人试玩验证理解、情绪峰值和再玩意愿。
