# M2 五板块分档增益模拟 v2

> 状态：已被 v3 取代。用户明确要求保留现有交通节点并新增4个项目节点；本报告将交通节点转为项目的拓扑假设不进入实现。

- 用户决策：5 个产业板块，每板块 5 个可投资项目；按个人参与项目数量逐档解锁，增益只作用于该板块自己的项目
- 样本：每个 profile 400 局、4 Bot、12 轮、固定 seed 从 1 开始
- 棋盘候选：保留45节点拓扑，在模拟中把4个交通节点转成可投资交通项目，使项目从21增至25
- 合伙计数：五五合伙项目对双方都计1个板块项目
- 原始工件：`artifacts/balance/m2-sector-candidates-v2.json`（验证工作区，不提交）

## 分档规则候选

- 1 个：显示已进入板块及下一档目标；
- 2 个：该玩家在该板块的项目分红增加；
- 3 个：允许在该板块建设三级旗舰项目；
- 4 个：获得板块主导城市分，不继续叠加租金；
- 第 5 个项目仍有自身投资、分红和阻挡价值，不增加第五套规则。

## 结论

1. 5×5 加分档增益解决了全收集死锁：cautious 每局约4.5个二档、0.7个三档，54%对局能出现旗舰解锁；四档保持稀有。
2. 三组候选四行动位胜率均显著比“新经济+后手加钱”公平。M2 下等额金币更合适；M1 的后手补偿不应直接迁移。
3. cautious 是唯一同时落在首轮目标范围内的方案：建设约8次、分红冲击15.4%、合伙约3次、三档真实可达。
4. target 的分红冲击仍可接受，但建设接近12次，可能让每回合操作过密；aggressive 的29.2%单次冲击和6.5次合伙都偏高。
5. 三组候选的重组仍偏少。是否增加失败压力应交给后续机遇/事件设计，而不是继续无限提高常规分红。
6. 最后三轮领先变化尚未改善，因为“验收季”和影响力公投尚未进入模拟；不能用当前结果判断终局机制。

## 推荐下一步

以 cautious 作为第一个可玩原型的经济基线：

- 等额 1500 初始金币 + 随机先手；
- 5 板块×5 项目；
- 二档板块分红 +10%；
- 三级旗舰分红倍率最高 ×3；
- 建设从第6轮开始，Bot 每局最多2次；
- 五五合伙率约20%，不做自由股比。

正式 UI 实现前仍需确定新增4个项目的产品名称与板块归属；当前模拟中的4个交通项目只用于验证25项目结构。
