# M2 扩展棋盘五板块模拟 v3

- 用户决策：保留现有交通节点；新增4个项目节点和独立图标；地图允许扩大
- 候选棋盘：45节点扩展为49节点，现有交通节点类型与奖励不变
- 新节点：钱塘会展中心、运河运动公园、滨江国际社区、大运河艺术馆
- 拓扑：两条内环各插入2个新项目节点
- 板块：5个板块×5个项目；独资或五五合伙对参与者均计1个
- 样本：每个 profile 400 局、4 Bot、12轮、固定 seed 从1开始
- 原始工件：`artifacts/balance/m2-expanded-candidates-v3.json`（验证工作区，不提交）

## 结论

1. 新增4个节点后，所有候选仍100%完成，没有非法状态或死循环；扩大棋盘不会破坏状态机。
2. cautious 仍最接近首个可玩原型：项目约15个、合伙约3次、建设约8次、二档约4.3次、54%对局出现三档、P90分红冲击14.6%。
3. target/aggressive 的合伙、建设和分红仍偏密，不适合作为第一版。
4. 新拓扑使第二行动位胜率升至30%–33%。正式原型必须随机先手，并继续调整新节点在两条内环的具体位置；不能把当前坐标视为最终地图。
5. 四档保持稀有（约每18局1次），符合“高光而非常规”的预期。
6. 重组仍然不应靠继续抬常规租金解决，后续由事件/机遇制造可控的大波动。

## 推荐原型参数

- cautious 经济档；
- 等额1500金币、随机先手；
- 二档板块分红 +10%；
- 3个项目解锁三级旗舰，最高分红倍率 ×3；
- 4个项目增加城市分与高光，不继续叠租金；
- 建设从第6轮开始，Bot 每局最多2次；
- 现有交通节点全部保留；新项目使用独立图标和新节点坐标。

UI/E2E 前必须完成一次49节点移动端无重叠布局；如果扩大棋盘需要滚动或缩放，优先保证节点可读和路线连续，不压缩回45节点尺寸。
