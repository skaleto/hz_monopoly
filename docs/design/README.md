# 数值设计文档

`杭城合伙局-数值设计-v0.6.4.xlsx` 是历史线上基线；`杭城合伙局-数值设计-M3候选.xlsx` 是已归档的 M3 候选；`杭城合伙局-数值设计-M4候选.xlsx` 对应已发布的 v0.8.0 数值设计，文件名保留候选阶段命名。

重新导出：

```bash
npm run docs:numeric
```

历史候选工作簿包含版本说明、节点类型、49 个地图节点、25 个项目、旧板块四档增益、12 张城市事件、事件选择、11 张道具卡、经济与计分。v0.8.0 起板块增益已被废止；M4 工作簿只保留项目类别说明，不再生成板块增益页，并已随 v0.8.0 合入发布。
