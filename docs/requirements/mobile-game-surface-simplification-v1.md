## 方向

- 目标用户: 在手机上进行 2–4 人熟人对局的玩家
- 问题/当前行为: v0.7.3 用板块栏、底部控制条和最近动态栏挤压棋盘，375×667 下整盘缩放约 0.632；板块还隐含分红、三级建设与结算奖励；掷骰入口像表单按钮而不是棋盘交互
- 期望结果: 对局面聚焦棋盘；移除板块全部玩法效果；本人可投掷时棋盘中央出现现有 WebGL 骰子的静止态，点击同一骰子后直接开始滚动；道具/建设/记录位于棋盘上方；棋盘文字和图案显著放大、边框变细
- 非目标: 不改 49 节点坐标、路线拓扑、投资/合伙/事件/道具规则，不直接修改生产环境
- 准确对象锚点: 正确基准 `main@578e262` / 生产 v0.7.3；验收代码 `0f85364`；候选版本 v0.8.0 / `hangzhou-v5-streamlined-board`
- 第一个验收样例: 375×667 中完整棋盘接近按宽度显示，板块/底部控制/动态三栏均不存在；仅当前可操作玩家看到中央骰子，点击后立即切换至 3D 投掷动画
- 当前视觉验收样例: 375×667 中顶部从四张同权数据卡收敛为一条连续玩家栏；“我”位于首位且更宽，以 2px 玩家色左线识别；三个对手仅常驻头像、姓名、金币、城市分和当前回合底色，点按可查看影响力与道具；按钮、玩家分区均不得回退为胶囊；棋盘顶部位置不大于 125px

## 推荐路径

- 推荐方案: 删除板块进度和全部档位效果，类别字段仅作说明；规则版本升为 `hangzhou-v5-streamlined-board`；短屏删除板块栏、底部控制条和动态栏，新增顶部工具条；中央骰子仅在本人 `roll` 阶段显示，待点击态和投掷态共用 `diceCanvas` 与 `HangzhouDiceRenderer`，按钮层只保留一行文字和点击命中区；文字 5→7px、项目图案 13→17px、普通图案 16→22px、格子边框/阴影 2→1px
- 推荐理由: 同时解决无价值规则、隐藏数值和屏幕空间三类问题；保留服务端权威投骰，不把随机逻辑下放客户端
- 什么证据会证明推荐错误: 板块事件或倍率仍可生效；三级建设仍受类别数约束；待点击态存在第二套骰子 DOM/素材；静止和滚动不是同一 canvas；他人回合出现中央骰子；点击后可重复提交；任一节点截断/遮挡；固定种子经济门禁失控
- 备选方案: 只隐藏板块 UI、保留规则；会产生不可见暗规则，已拒绝
- 当前成熟度允许的动作: v0.8.0 已发布并保留；后续改动从该生产基线另开隔离分支/worktree
- v0.8.1 视觉增量推荐路径: 单层连续玩家栏代替四张同权卡；我的区约为对手区 1.35–1.5 倍宽并延续 2px 玩家色左线；对手区常驻信息不超过头像、姓名、金币、城市分和回合高亮，点按详情恢复影响力/道具；顶部控制统一为 28px 软方形；联机文字收为状态点；回合/位置去掉整条白底表单感，成为棋盘冠层
- v0.8.1 当前成熟度允许的动作: D2 隔离原型、自动化测试、双尺寸截图和 Claude 复测；未获用户验收前不得合入或发布
